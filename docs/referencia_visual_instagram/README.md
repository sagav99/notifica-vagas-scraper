# Referência visual do carrossel do Instagram

Screenshots reais dos 4 slides de um post já publicado em `@medvagasapp`,
criado manualmente pelo usuário antes do pipeline automático. **Layout-fonte
aprovado pelo usuário em 2026-09-29** — decisão registrada, não reabrir sem
motivo novo. O pipeline automático (`src/notifica_vagas_scraper/instagram/card.py`,
`montar_htmls`) reproduz este layout para o post diário.

- `slide-1-vaga-da-semana.png` — 1/4, resumo da vaga (eyebrow, headline
  2 cores, card com dados da vaga, "DESLIZE PARA O LADO →").
- `slide-2-valor-hora.png` — 2/4, destaque de valor-hora.
- `slide-3-checklist-edital.png` — 3/4, checklist fixo "confira sempre o
  edital oficial".
- `slide-4-cta-preview.png` — 4/4, CTA + preview de outras 2 vagas + preço.
